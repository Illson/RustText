# Демо RustText на .NET 11

Окно Avalonia 12.1.6 показывает встроенный журнал, фильтрует строки без учёта регистра и выводит текущее число совпадений. Строки можно выделить и скопировать. Для демо достаточно встроенных данных.

## Быстрый запуск

Из корня репозитория в PowerShell на Windows x64. Нужен SDK .NET 11.

```powershell
Set-Location prototype/avalonia
dotnet run
```

## Публикация Native AOT

Нужен компонент Visual Studio «Разработка классических приложений на C++» с Windows SDK.

```powershell
dotnet publish -c Release -r win-x64
& .\bin\Release\net11.0\win-x64\publish\RustText.Demo.exe
```

Команды публикации выполняются из `prototype/avalonia`. Для переноса на другую машину скопируйте весь каталог `publish` вместе с библиотеками отрисовки. Отдельная установка .NET для запуска опубликованной сборки не требуется.

## Проверка

В Debug окно показывает `JIT`, после публикации — `Native AOT`. При вводе `warn` остаются две строки. Запрос без совпадений показывает «Совпадений нет». После очистки фильтра снова видны все 12 строк.

При подробном выводе публикации (`-v normal`) Avalonia 12.1.6 выдаёт два сообщения ILC о сигнатурах DirectComposition. Ошибка отслеживается в [Avalonia #22817](https://github.com/AvaloniaUI/Avalonia/issues/22817).
