# RustText на Avalonia

Редактор и просмотрщик больших логов для Windows x64. Проект использует .NET 11, Avalonia и AvaloniaEdit. Путь к файлу можно передать при запуске.

## Запуск и сборка

Нужен SDK .NET 11. Команды выполняются из `prototype/avalonia`.

```powershell
dotnet run
dotnet run -- 'C:\логи\пример.log'
```

Для Native AOT нужен компонент Visual Studio «Разработка классических приложений на C++» с Windows SDK.

```powershell
dotnet publish -c Release -r win-x64
& .\bin\Release\net11.0\win-x64\publish\rusttext.exe 'C:\логи\пример.log'
```

Для переноса скопируйте `rusttext.exe`, `av_libglesv2.dll`, `libHarfBuzzSharp.dll` и `libSkiaSharp.dll` в одну папку. Сборка включает среду выполнения .NET.

## Оформление «Фокус»

В тёмной рабочей области графитовые меню и вкладки отделены от серо-синего редактора. По умолчанию текст документа и лога отображается размером 12 px. Выбранный пользователем масштаб сохраняется между запусками.

Вкладки и кнопки групп размещены в одной строке. При наведении подсвечивается поверхность вкладки, а верхний акцент отмечает выбранный документ. Поиск открывается под текстом. У лога управление обновлением расположено вверху, навигация внизу, миникарта справа.

## Работа с файлами

- `Ctrl+N` создаёт вкладку, `Ctrl+O` открывает файлы. Вкладки можно перетаскивать между группами. Кнопки справа от вкладок разделяют рабочую область. `Ctrl+Shift+T` восстанавливает закрытые вкладки.
- `Ctrl+S` сохраняет документ с проверкой внешних изменений, `Ctrl+Shift+S` позволяет выбрать другой путь. Доступны UTF-8, UTF-16 с BOM и явное открытие в Windows-1251.
- `Ctrl+F` открывает поиск, `Ctrl+H` показывает замену, `F3` и `Shift+F3` переходят между совпадениями. Форматирование JSON, переход к строке, генератор, сравнение списков и версии файлов доступны в меню «Инструменты».
- Файлы крупнее 50 МиБ открываются постранично. Для меньших файлов используйте «Файл → Открыть как лог…». В просмотре доступны поиск, переход по проценту и времени, фоновый индекс, миникарта, слежение за концом и операции с началом файла.

## Сессия и Windows

Профиль Avalonia расположен в `%LOCALAPPDATA%\RustText\dotnet-demo`. При первом запуске новая версия может прочитать старые настройки, недавние файлы и сессию RustText. Для изолированной проверки задайте `RUSTTEXT_PROFILE_DIR` абсолютным путём к тестовому каталогу перед запуском.

Повторный запуск с тем же профилем передаёт пути уже открытому окну. Команда «Файл → Настроить открытие файлов в Windows…» регистрирует текущий EXE и открывает параметры приложений по умолчанию. Для проверки обновления используйте меню «Инструменты». Автоматическая проверка включается в настройках. Пакет Avalonia использует отдельные имена `RustText.NET-win-x64.zip` и `RustText.NET-win-x64.zip.sha256`. В корне архива размещаются EXE и три DLL из каталога публикации.

При публикации Avalonia 12.1.6 компилятор может вывести два сообщения о сигнатурах DirectComposition. [Avalonia #22817](https://github.com/AvaloniaUI/Avalonia/issues/22817)
