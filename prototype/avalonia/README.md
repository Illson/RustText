# Демо RustText на .NET 11

Демо на Avalonia 12.1.6 показывает встроенный журнал и открывает локальные UTF-8 логи через кнопку «Открыть лог…» или аргумент запуска. Текст страницы можно выделить и скопировать. Фильтр ищет по текущей странице без учёта регистра.

Кнопки «В начало», «Назад», «Дальше» и «50%» перемещают область чтения. «Назад» возвращается по истории последних 128 переходов. Внизу показаны диапазон прочитанных байтов и размер файла. Страница вмещает до 80 строк или фрагментов и охватывает до 128 КиБ исходных данных. Длинные строки отображаются фрагментами. Если пишущая программа заменит файл по тому же пути, для чтения нового файла откройте его снова.

## Быстрый запуск

Из корня репозитория в PowerShell на Windows x64. Нужен SDK .NET 11.

```powershell
Set-Location prototype/avalonia
dotnet run
dotnet run -- 'C:\логи\пример.log'
```

## Публикация Native AOT

Нужен компонент Visual Studio «Разработка классических приложений на C++» с Windows SDK. Выполняйте из `prototype/avalonia`.

```powershell
dotnet publish -c Release -r win-x64
& .\bin\Release\net11.0\win-x64\publish\RustText.Demo.exe 'C:\логи\пример.log'
```

Для переноса на другую машину скопируйте весь каталог `publish` вместе с библиотеками отрисовки. Сборка включает среду выполнения .NET.

## Проверка

В Debug окно показывает `JIT`, после публикации — `Native AOT`. При вводе `warn` во встроенном журнале остаются две строки. Запрос без совпадений показывает «Совпадений нет». После очистки фильтра снова видны все 12 строк.

Для проверки чтения откройте тестовый UTF-8 лог, перейдите вперёд, вернитесь назад и нажмите «50%». Внизу изменится диапазон байтов. Сценарий и результаты для файла 20 ГиБ приведены в [отчёте о проверке](../../docs/verification.md#avalonia-и-rust-на-логе-20-гиб).

При подробном выводе публикации (`-v normal`) Avalonia 12.1.6 выдаёт два сообщения ILC о сигнатурах DirectComposition. [Avalonia #22817](https://github.com/AvaloniaUI/Avalonia/issues/22817)
